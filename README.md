# Bakerwood Website — External Publishing Package

This is a **self-contained React/Vite version** of the Bakerwood website, prepared for use in Visual Studio Code and for deployment to Netlify or Vercel.

All website images are included in `public/images`. The project does not rely on Manus-hosted image URLs.

## Quick start

1. Install Node.js 18.14 or newer.
2. Open this folder in VS Code.
3. In VS Code's terminal, run `npm install`.
4. Run `npm run dev` and open the local address shown in the terminal.
5. Before publishing, run `npm run check` and then `npm run build`.

See the accompanying **Bakerwood VS Code and Publishing Guide** for the complete process.
